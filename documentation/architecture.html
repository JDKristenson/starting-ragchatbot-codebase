Course-materials RAG architecture

Source-derived map · reviewed 2026-11-12 · not a running-system capture

Accessible flow summary

  1. The browser sends questions and session identifiers to FastAPI. The API returns answer text, source labels and the session identifier.
  2. RAGSystem coordinates generation, local search and bounded process-memory conversation history.
  3. On startup, existing course text is parsed into metadata and overlapping chunks, then indexed in local persistent Chroma collections with sentence-transformer embeddings.
  4. AIGenerator sends the question and available history to Anthropic. When the provider requests a search tool, Python searches Chroma locally and sends retrieved excerpts in a follow-up API call.
  5. Answers return through the orchestrator and API to the browser. Embedding model downloads and the browser's existing Markdown CDN script are additional network boundaries.
